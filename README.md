# 去远方 · Faraway

一只橘猫的旅行手账 —— 跑在 [FoloToy AI Passport](https://github.com/FoloToy/ai-passport) 上的竖版收集小游戏（240×320）。

> 在家上班的人，也想去看看远方。于是橘猫背上小书包，替你去。

## 玩法

在主页底部挑一趟行程 —— 试玩 15 秒 / 5 分钟 / 1 小时 / 4 小时 / 12 小时，走得越久去的地方越远。
按 `●` 送它出门，时间到了它会带回一张当地的明信片和一件小纪念品。

| 按键 | 主页 | 旅行中 | 收藏册 | 设置页 |
|---|---|---|---|---|
| `↑` `↓` | 选择行程 | 关闭屏幕 | 翻页 / 换条目 | 调节屏幕亮度 |
| `●` 短按 | 确认 | 进入收藏册 | 进入 / 收下 | 返回 |
| `●` 长按 | 关闭屏幕 | 快速回家（花猫罐头） | 返回 | — |

电源键是硬件直连的断电路径，固件读不到它 —— 这就是"开关机"。

- **24 个目的地** —— 从婺源的油菜花海、西塘的青石窄巷，一路铺到敦煌的鸣沙山和塔克拉玛干的沙脊
- **24 件纪念品** —— 收藏册里排成两页、每页 3×4；还没收到的只留一个灰色剪影、连名字都不写
- **4 个小游戏** —— 接猫罐头 / 打兔子 / 和猫猜拳 / 记忆翻牌，每收满 6 张明信片解锁一个
- **天气图层** —— 雨、雪、雾、萤火，天上有时候还会飞过小飞机、热气球和肥皂泡泡
- **猫咪对我说的话** —— 在家和在路上各有一套台词

离线可玩，不用配网。

## 构建

需要 ESP-IDF **v5.5.3**（与上游一致），目标芯片 ESP32-C3。

```bash
# WiFi 校时是可选的：不填就走手动设置时间那条路，游戏完全不受影响
cp main/secrets_wifi.example.h main/secrets_wifi.h

idf.py set-target esp32c3
idf.py build
idf.py -p <串口> flash
```

**目标板必须是 8 MB Flash。** 分区表把 app 划到 `0x7F0000`，4 MB 板刷进去会无限重启。

`main/fa_sprites.bin`（约 6.6 MB 的精灵图集）和 `main/fonts/*.c`（五支中文字库）**已经提交**，
所以 clone 下来直接就能编译，不需要跑素材流水线。

只有在要改素材时才需要这两个生成脚本：

- `tools/gen_fa_sprites.py` —— 从 `art/out/*.i8` 打包精灵图集
- `tools/gen_fa_fonts.py` —— 扫 `main/*.c` 里的字符串字面量生成字库（写进源码的字必然能显示）

## 与上游的关系

本分支 fork 自 [FoloToy/ai-passport](https://github.com/FoloToy/ai-passport)，
基线是官方 `main` 的 `1051209`（2026-09-20）。

按官方 fork 约定，fork 的 `main` 分支只用来同步上游，
**本应用的全部改动都在 `feature/faraway` 这一条分支上** ——
包括 `main/` 下新增的 `fa_*.c` / `tb_*.c`、`tools/` 下新增的生成脚本，
以及 `main/CMakeLists.txt` 的 SRCS 改动。

`components/bsp/` 保持上游原样，未作任何修改。
